# Отчёт по реализации спеки `two-quolegs.md`: только факты

Без выводов и интерпретаций. Полные таблицы в `results.md`, решения в `decisions.md`.

## Что построено

Python, numpy, torch. Тор 16×16, окно 5×5, два симметричных агента, еда, энергия, респаун. Три MLP на агента
(2 скрытых слоя по 64), онлайн-обучение через буфер 4000 и Adam. Планировщик: полный перебор 5³ цепочек
на горизонт 3 по W и модели-водителю, критерий — сумма предсказанной энергии. Проводка — отдельный конфиг,
как в спеке. Слой интроспекции получает модели только как массивы весов, выходы на фиксированной пробе
и истории ошибок/обновлений; не импортирует проводку. Всё детерминировано по seed.

Отступления от спеки:
- Агентная модель получает на вход не только `(state, a)`, но и окно еды 5×5 вокруг актора (иначе не может
  предсказать энергию). Оба потока содержат окно вокруг своего актора, точно.
- Стен нет (тор). Позиция кодируется `(cos, sin)` по каждой оси.
- Смерть кодируется как энергия 0 в цели предсказания; респаун между шагами в цель не попадает.
- Epsilon-greedy 0.1 у обоих агентов.
- Копия команды — вход модели `a_t`, не отдельное поле состояния.
- Дополнительно логируется «ошибка управления»: предсказание модели по команде *владельца агента*
  (а не актора её потока) против факта на её потоке. В интроспекцию не передаётся.
- Флаг `use_other_in_planning` (по умолчанию выкл.): планировщик вычёркивает еду в клетке, куда, по модели
  другого потока, придёт другой агент.

## Прогоны

Базовый конфиг: 4000 шагов, распад 0.02/шаг, еда +0.3, до 12 еды, спавн 0.25.
Эталоны (последняя четверть, смертей на 1000 шагов на агента): случайная политика 41.6 (энергия 0.24),
обученный агент 4–9 (0.6–0.7), оракул с окном 5×5 и точной физикой 2.0 (0.75), оракул со всей картой 0.0 (0.94).

### Тест перестановки ролей (20 + 20 seed'ов)
Проводка S/O поменяна местами, код не менялся. Водитель планировщика: «O». Энергия A: 0.619 против 0.617,
KS p = 0.34. Ошибка на потоке «я»: обычная проводка S 0.00078 / O 0.00126; перевёрнутая S 0.00124 / O 0.00079.

### E1 (10 seed'ов, обучение 4000 шагов)
E1a, указатель на O, провода не тронуты, 1500 шагов. Последняя тысяча до / после:
энергия A 0.62 / 0.30 (падение у всех 10 seed'ов, минимум 0.16); смертей A 6.7 / 35.4; энергия B 0.64 / 0.68;
ошибка S на потоке «я» 0.00080 / 0.00065; ошибка O на потоке «я» 0.00133 / 0.00081;
ошибка управления S 0.00080 / 0.00065; ошибка управления O 0.050 / 0.043.

E1b, O перепаяна на `internal_state` (вход и цель), буфер очищен, 3000 шагов. RMS расстояние выходов O и S:
обученная O на реальных входах 0.035 → 0.027; свежая O на реальных входах 0.68 → 0.040; свежая O на пробе
0.68 → 0.065; кривая ещё убывает. Расстояние S_A против S_B на пробе 0.060. Корень из ошибки S: 0.019.

### E2/E3 (200 прогонов, 400 пар S/O, 800 моделей)
Предпроверки. Симметрия A/B: энергия 0.631 / 0.626 (KS p 0.92), ошибка S 0.000796 / 0.000786 (p 0.33),
смертей 6.8 / 7.0 (p 0.92). Потоки S и O (по 102 400 примеров): максимальная стандартизованная разница
средних по входам 0.011, по целям 0.005; KS по энергии p 0.98; частоты действий совпадают до 3-го знака.

Классификаторы: логрегрессия и случайный лес, GroupKFold по прогону, перестановочный тест 100 перестановок.

E2, точность self/other по содержимому:
- спектры сингулярных чисел + отсортированные смещения: 0.496
- + статистики активаций на пробе: 0.535
- + выходы на пробе (256 фиксированных входов): 0.818 [0.79, 0.84] без пар; 0.900 [0.87, 0.93] парный
  (перестановочный p < 0.01)
- контроль W против S по спектрам + смещениям: 1.000

Парная разность выходов S − O на пробе (400 пар): по четырём компонентам позиции средняя ≈ 0, |t| < 1.7;
по энергии −0.0144, t = −20.5. Средняя предсказанная энергия на пробе: S 0.483, O 0.497, истинная 0.495.
Сдвиг присутствует во всех подгруппах пробы (есть/нет еды в целевой клетке, любая энергия, любое действие);
при действии «стоять» −0.020.

E3, точность self/other по динамике (вторая половина прогона):
- только ряды ошибок и обновлений: 0.568 [0.53, 0.60] без пар (p < 0.01), 0.610 парный
- + ряд собственных команд агента: 0.983 [0.97, 0.99] без пар, 0.998 парный
Наибольшие веса логрегрессии: кросс-корреляция log-ошибки со сменой собственной команды на лагах +1, −1, ±3,
затем средняя log-ошибка при условии собственной команды.
