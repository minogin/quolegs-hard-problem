# Документация проекта «Два кволега»

Точка входа. Что в каком файле и когда его обновлять.

| Файл | Что там | Когда обновлять |
|---|---|---|
| `two-quolegs.md` | Спека: теория (п. 1–9) и инструкция для Claude Code (среда, агент, проводка, эксперименты E1–E5). Не редактируется, кроме как по решению Андрея. | Редко |
| `plan.md` | Статус: что сделано, что в очереди, что заблокировано. Порядок работ и текущая позиция. | После каждого этапа |
| `results.md` | Результаты каждого прогона: что запускали, числа, графики (`figures/`), вывод, оговорки. | После каждого прогона |
| `decisions.md` | Решения, влияющие на результат: отступления от спеки, параметры, дизайн (D1, D2, ...). | Когда принято решение |
| `ideas.md` | Наблюдения, гипотезы, аналогии с человеком, открытые вопросы (I1, I2, ...). | После обсуждений |
| `analogies.md` | Аналогии с человеком (A1, A2, ...): что у человека, что в модели, какой эксперимент, насколько точно. Слой интерпретации. | После обсуждений |
| `brief.md` | Выжимка для автора спеки: что построено, отступления, все числа. Без выводов и интерпретаций. | После каждого прогона |
| `figures/` | Графики из `results/`, на которые ссылается `results.md`. `results/` в gitignore, поэтому копии здесь. | Вместе с `results.md` |

Ссылки между файлами: решения ссылаются на идеи (D5 → I1, I2), идеи на решения (I9 → D12) и на аналогии
(I7 → A1–A5), результаты на всё. Код ссылается на решения в комментариях (`D4`, `D12`).

Код: `quolegs/` (ядро), `quolegs/experiments/` (эксперименты), `tools/` (вспомогательные скрипты),
`run_all.py` (запуск одной командой). Правила работы — в `CLAUDE.md` в корне.
