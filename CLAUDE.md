# Правила работы в этом проекте

1. Перед принятием важных решений спрашивать Андрея.
2. Перед запуском долгих прогонов спрашивать разрешение.
3. Объяснять Андрею написанный код и принятые решения простым языком.
4. Останавливаться после завершения большого этапа.
5. Комментарии в коде — на английском, по смысловым блокам, объясняют «зачем», а не «что».
   Отступления от спеки и нетривиальные решения — ссылкой на `docs/decisions.md` (D1, D2, ...).
6. После больших изменений сразу коммитить и пушить в `origin` (github.com/minogin/quolegs-hard-problem), не спрашивая.

# Проект

Модель двух кволегов: спека в `docs/two-quolegs.md`. Код на Python (numpy + torch), venv в `.venv`,
запуск: `.venv/Scripts/python run_all.py [--quick]`.
